# Audio Pipeline Gate Verification

**Date:** 2026-07-28  
**Scope:** POC audio-condition pipeline only  
**Status:** Gate closed

## Measurement method

RMS was measured after a 4 kHz or 6 kHz FFmpeg high-pass filter using the
`astats` filter's overall `RMS level dB` value:

```bash
ffmpeg -hide_banner -i INPUT \
  -af "highpass=f=4000,astats=metadata=1:reset=0" \
  -f null -
```

The same command was repeated with `highpass=f=6000`. The clean input was
`/tmp/poc-noise.wav`; the derived artifacts were the `noise_test` outputs in
`voice-eval/.work/noise_test/`.

## Results

| Audio artifact | High-pass RMS at 4 kHz | High-pass RMS at 6 kHz | Differential falloff |
|---|---:|---:|---:|
| `clean-source` (`/tmp/poc-noise.wav`) | -5.872768 dB | -6.258059 dB | 0.385291 dB |
| `whatsapp-16k.ogg` | -15.093966 dB | -18.182834 dB | 3.088868 dB |
| `telephony-16k.wav` | -24.076721 dB | -38.190460 dB | 14.113739 dB |

The 8 kHz mu-law intermediate, `telephony-8k-mulaw.wav`, produced `-inf` RMS
after the 4 kHz high-pass check. This is the expected narrowband boundary
result; the 6 kHz value is not used as a gate measurement for an 8 kHz signal.

## Conclusion

Condition C is verified as genuinely narrowband. Its residual energy above
4 kHz is filter-skirt leakage rather than resampler imaging: the telephony
condition has a 14.11 dB differential falloff from 4 kHz to 6 kHz, compared
with only 3.09 dB for the WhatsApp condition. The audio pipeline gate is
closed.
